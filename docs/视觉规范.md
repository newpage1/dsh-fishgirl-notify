## 1. 角色设定

### 1.1 一句话

一条圆润、呆萌、爱报喜的小鱼娘：深海蓝短发、珊瑚粉鱼鳍耳、奶油水手裙和一条会摆动的双瓣鱼尾；完成时挥手说「做好啦」，失败时眼泪汪汪说「出错了」。

### 1.2 外形识别点（不可随意改动）

- **头身比约 1:1** 的 chibi 比例，脸颊圆、下巴短，整体像一颗水滴。
- **头发**：深蓝渐变短发（`#4390C2 → #245C88`），刘海呈波浪锯齿边；头顶一根卷曲**呆毛**，呆毛末端挂一颗小水滴。
- **鱼鳍耳**：珊瑚粉扇形鳍（`#FFB9C8 → #FF7F9E`），外缘波浪扇贝，内部 3 根鳍线（`#E06381`）；左右对称，是角色最重要的识别点。
- **眼睛**：大眼、深蓝渐变虹膜、白色大高光 + 小星形高光；上睫毛粗、下眼睑细。眨眼时是两道向下弯的月牙线。
- **服装**：奶油色水手裙（`#FFF8F0 → #FFE7D3`），深蓝水手领（`#2C5680`），胸前珊瑚蝴蝶结（`#FF8FA3`），围裙上有薄荷小鱼补丁（`#7FE3D8`），裙摆一道珊瑚细边。
- **尾巴**：珊瑚粉双瓣尾鳍，内缘奶白高光，可左右摆动；失败时尾巴下垂。
- **四肢**：短胖胳膊、短胖腿、粉色圆头鞋；手是简单的圆手套造型。
- **表情**：成功为张嘴笑 + 腮红；失败为担心眉 + 水汪汪大眼 + 波浪嘴 + 雨云/汗滴；等待为闭眼 + 小圆嘴 + 思考气泡。

### 1.3 性格与文案

- 语气：活泼、治愈、有点憨，不卖萌过度，不抢 DSH 主界面的风头。
- 成功主文案：**「做好啦」**；副文案可用「任务完成 · 肥鱼娘来报喜」「这一回合结束，去看看结果吧」。
- 失败主文案：**「出错了」**；副文案「再试一次，肥鱼娘陪着你」。
- 等待文案：「还在想…」「马上就好」。
- 不使用感叹号堆叠、不使用网络烂梗；中文为主，可保留 `DSH` 英文标识。

### 1.4 风格边界

- 粗描边（`#22304F`，在 1024 画布上约 6–10px）、扁平色块为主，少量线性渐变和高光；不做厚涂、不做 3D 写实。
- 可参考 `@linxin666/dsh-pet` 的 whale-refined 的**深海配色 + chibi 比例**作为风格方向；**未复制**其任何像素、路径、配色文件或角色设定，本角色为独立原创。
- 禁止：拉伸变形、裁掉呆毛/鳍耳/尾鳍、把角色叠在低对比纯蓝背景上、在角色身上直接压文字、改变「做好啦」的语气。

## 4. 动效规范

### 4.1 时间轴（默认 3.0s，播放一次；`.is-looping` 可循环）

| 时间 | 进度 | 事件 | 实现 |
|---|---|---|---|
| 0.00–0.24s | 0–8% | 卡片淡入 + 上移 12px | `fg-card-cycle`，`ease-out` |
| 0.00–0.27s | 0–9% | 角色从下方 30px、0.76 倍弹到 -12px、1.07 倍 | `fg-char-cycle`，`cubic-bezier(.34,1.56,.64,1)` |
| 0.27–0.45s | 9–15% | 回弹下沉到 +2px、0.97 倍 | 同上 |
| 0.45–0.63s | 15–21% | 稳定到 1.0 倍 | 同上 |
| 0.36–0.60s | 12–20% | 气泡从 0.7 倍、下移 8px 弹出到 1.05 倍 | `fg-bubble-cycle`，回弹缓动 |
| 0.60–0.81s | 20–27% | 气泡稳定到 1.0 倍 | 同上 |
| 0.36–2.52s | 12–84% | 气泡保持；84% 后淡出 | 同上 |
| 0.8–2.3s | — | 眨眼 / 摆尾 / 星星闪烁 | 独立循环动画 |
| 2.11–2.21s | 88–92%（2.4s 眨眼周期） | 闭眼一帧 | `fg-blink` / `fg-blink-open` |
| 2.58s | 86% | 卡片与角色开始淡出 | `fg-card-cycle` / `fg-char-cycle` |
| 3.00s | 100% | 完全消失（气泡已于 2.52s 消失） | — |

**独立循环参数**

| 动画 | 时长 / 缓动 | 关键帧 |
|---|---|---|
| 呼吸浮动 `fg-bob` | 1.4s，`ease-in-out`，无限 | 0%/100% `translateY(0)`；50% `translateY(-4px)` |
| 尾巴摆动 `fg-tail-sway` | 1.6s，`ease-in-out`，`alternate` 无限 | `rotate(-3.5deg)` → `rotate(3.5deg)`；`transform-origin: 55% 68%`（尾巴根部） |
| 眨眼 `fg-blink` / `fg-blink-open` | 2.4s，`steps(1,end)`，无限 | 0–85% 睁眼/闭眼隐藏；88–92% 闭眼/睁眼隐藏；95–100% 恢复 |
| 星星闪烁 `fg-twinkle` | 2.2s，`ease-in-out`，无限 | opacity .55→1，scale .985→1.015 |
| 气泡星 `fg-star-pop` | 2.2s，`ease-in-out`，无限 | opacity .35→1，scale .85→1.15，rotate 0→18deg |

**失败态时间轴（`fg-error-cycle`，3s）**

| 时间 | 事件 |
|---|---|
| 0–0.30s | 从下方 18px、0.82 倍弹入，10% 时 1.04 倍 |
| 0.60–0.96s | 左右抖动：-7px → +6px → -4px → 0 |
| 0.96–2.28s | 保持（眼含泪、雨云、尾巴下垂） |
| 2.28–3.00s | 淡出并轻微缩小 |

失败气泡：底色 `#FFF4F0`，标题 `#B23A52`；无金色星星；角色使用 `fishgirl-hero-error.png`（或 `.fg-char-static`）。

### 4.2 分层与结构

```
.fg-pop[data-state="success"]
  .fg-scene                     卡片：16:10，圆角 28，渐变底 + 珊瑚/DSH 蓝光晕
    .fg-char                    角色：宽 58%，左下定位，transform-origin 50% 82%
      .fg-layer.fg-shadow       地面软阴影
      .fg-tail-wrap             尾巴容器，独立 rotate
        .fg-layer.fg-tail
      .fg-idle                  呼吸浮动
        .fg-layer.fg-body
        .fg-layer.fg-eyes.fg-eyes-open
        .fg-layer.fg-eyes.fg-eyes-closed
        .fg-layer.fg-sparkles
    .fg-bubble                  奶油气泡，右下小尾巴朝向左下
      <strong>做好啦</strong><span>任务完成 · 肥鱼娘来报喜</span>
```

- 六层 PNG 都是 1024×1024 同画布，CSS `inset:0` 叠放即对齐；不要单独裁切/缩放某一层。
- 气泡 `transform-origin: 8% 78%`（尾巴根部）；卡片圆角 28px；角色 `left:-2%; bottom:-6%`；气泡 `right:2.5%; top:13%; width:41%`。
- 深/浅主题通过 `.fg-theme-light` / `[data-theme="light"]` 或 `prefers-color-scheme` 自动切换；角色素材不换色。
- 安全区：弹窗 `bottom: max(18px, env(safe-area-inset-bottom))`；`width: min(92vw, 380px)`；iPhone SE 下 340px 宽、气泡字号 20px（见 CSS 媒体查询）。

### 4.3 reduced-motion 与静态替代

宿主可加 `.fg-static`，或由 `@media (prefers-reduced-motion: reduce)` 自动触发：

- 所有动画 `animation: none`；卡片、角色、气泡 `opacity: 1; transform: none`。
- 角色静态定位 `left:-2%; bottom:-7%`；睁眼层显示，闭眼层 `display:none`；阴影透明度 0.85。
- 不眨眼、不摆尾、不闪星、不弹跳；**内容与文案完全一致**，仅去掉运动。
- 真实通知建议只播一次（`both` 填充），不要自动循环；演示页可用「循环播放」按钮或 `.is-looping`。
- 无障碍：弹窗建议 `role="status" aria-live="polite"`；3s 内结束；不出现 >3Hz 的闪烁；正文对比度满足 AA；点击/关闭热区 ≥44px（由 t4 实现）。

## 5. 通知 / PWA 使用

### 5.1 Web Push（Android Chrome）

```js
// 通知大图：2:1，中心 60% 安全区
const image = '/assets/notify-card.png';   // 实际前缀以插件静态路由为准
new Notification('做好啦', {
  body: '任务完成 · 肥鱼娘来报喜',
  icon: '/assets/icon-192.png',
  badge: '/assets/icon-badge-96.png',
  image,
  tag: 'dsh-finish-notify',
  renotify: false
});
```

- `notify-card.png` 为 1024×512、`#0F1115` 深色底；如果宿主裁成 1:1，主体仍在中心 60% 安全区。
- 通知 icon 用 192×192；大图/分享用 512；单色 badge 用 96×96 白色小鱼剪影。
- 文案：标题「做好啦」，正文「任务完成 · 肥鱼娘来报喜」；失败标题「出错了」，正文「再试一次，肥鱼娘陪着你」。

### 5.2 PWA manifest

```json
{
  "icons": [
    { "src": "icon-192.png", "sizes": "192x192", "type": "image/png" },
    { "src": "icon-512.png", "sizes": "512x512", "type": "image/png" },
    { "src": "icon-maskable-512.png", "sizes": "512x512", "type": "image/png", "purpose": "maskable" }
  ]
}
```

- iOS 主屏：`apple-touch-icon-180.png`（180×180，无透明）。
- 支持 SVG 的宿主可复用 `icon.svg`（11.4 KiB，自包含矢量）。
- Service Worker 预缓存建议：`fishgirl-hero.png`、`fishgirl-hero-error.png`、`fishgirl-blink.png`、六层 PNG、`icon-192/512`、`notify-card.png`、`fishgirl-animation.css`；`preview/` 与 `src/` 不建议进缓存。
- 飞书/ntfy 等纯文本通道：不需要图片；如需附图，用 `notify-card.png` 或 `notification-banner-1024x512.png`。

### 5.3 文件命名

- 根目录运行时素材全部 ASCII、无空格、无中文；CSS 内使用相对路径 `url("./fishgirl-*.png")`，因此 CSS 与 PNG 必须在同一目录。

### 6.4 实现细节（给 t4）

- 眨眼：`fg-blink` 控制 `.fg-eyes-closed` 的透明度，`fg-blink-open` 同步把 `.fg-eyes-open` 透明度降到 0（闭眼 PNG 是透明底弧线，若不隐藏睁眼层会叠出“睁眼+弧线”）。已修入 `fishgirl-animation.css`。
- `?freeze=秒` 的实现依赖 `animation-delay: calc(-1 * var(--freeze))` + `animation-play-state: paused`；冻结时同时隐藏演示页的 `.hint`，避免分镜穿帮。
- 失败态既可用单张 `fishgirl-hero-error.png`（`.fg-char-static`），也可用分层尾巴/眼睛切换；推荐单图，减少 DOM。
